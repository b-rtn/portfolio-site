# Full Stack Developer Portfolio

A responsive React portfolio based on the interactive concept mockup.

## Run locally

1. Install Node.js (version 20.19+ or 22.12+) and pnpm.
2. In this folder, run `npm install`.
3. Run `npm dev` and open the local address shown in the terminal.

## Personalize

Update the placeholder copy and project information in `src/App.jsx`. Replace the `#` project links with your GitHub repository, live demo, or case study URLs when ready. The site is static and does not need a backend.

## Production build

Run `npm build`. The static site is written to `dist/` and can be hosted by a static web host.
